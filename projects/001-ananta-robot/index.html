Project Ananta

Distributed Fault-Tolerant Robotic System

A distributed robotic system designed to detect controller failures, reassign critical responsibilities, and continue operating in a degraded but safe state.

The idea

Instead of relying on a single controller, the robot will distribute sensing, control, health monitoring, and other responsibilities across multiple embedded nodes.

The project will explore questions such as:

  • How quickly can one node detect that another has failed?
  • How should control responsibilities be reassigned?
  • What state needs to be shared or replicated?
  • What happens when communication becomes unreliable?
  • How much redundancy is useful before complexity outweighs the benefit?
  • How should the system degrade when full operation is no longer possible?

Initial direction

The first version is expected to use multiple embedded controllers connected over CAN.

Possible responsibilities include:

  • motor control
  • sensing
  • system supervision and health monitoring
  • backup control
  • higher-level planning

The exact architecture will evolve as the system is built and tested.

Experiments

The project will involve deliberate failure injection, including shutting down or disconnecting controllers while the robot is operating.

Measurements will include:

  • fault-detection latency
  • failover latency
  • recovery success rate
  • communication bandwidth
  • CPU and memory usage
  • degraded-mode performance
  • failure and recovery statistics

Status

The project is currently in the architecture and system-definition stage.

Initial work will focus on defining the failure model, node responsibilities, communication architecture, and the smallest system capable of demonstrating real controller failover.
